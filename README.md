# Freedom Mukanza — Developer Portfolio

Professional Next.js portfolio for Freedom Mukanza.

## Stack
- Next.js App Router
- React + TypeScript
- CSS
- Lucide icons

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Build

```bash
npm run build
npm start
```

## Deploy to Vercel
Push the folder to GitHub and import the repository into Vercel. No environment variables are required.
