# Freedom Mukanza — Developer Portfolio

Professional Next.js portfolio for Freedom Mukanza.

## Stack
- Next.js App Router
- React + TypeScript
- CSS
- Lucide icons

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Build

```bash
npm run build
npm start
```

## Personalization
- Put your real resume at `public/Freedom_Mukanza_Resume.pdf` so the Resume button works.
- Replace the placeholder GitHub project URLs in `app/page.tsx` with direct repository links when available.
- Add a professional profile photo to `public/profile.jpg` later if desired.

## Deploy to Vercel
Push the folder to GitHub and import the repository into Vercel. No environment variables are required for the current version.
